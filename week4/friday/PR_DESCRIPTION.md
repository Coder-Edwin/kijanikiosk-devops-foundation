## Week 4 Friday: KijaniKiosk full IaC pipeline (AWS cloud path)

This PR adds `week4/friday/`, a pipeline in which Terraform provisions three Ubuntu 22.04 servers (api, payments, logs) from one reusable `app_server` module called with `for_each`, with state in an encrypted, versioned S3 bucket that has locking (`use_lockfile`). `pipeline.sh` then writes `inventory.ini` from `terraform output -json` and runs an Ansible playbook that brings every server to the Week 3 baseline: packages, service accounts, directories, hardened systemd units, ufw, persistent journald and logrotate. All per-server values are in `host_vars` and every config file comes from a `.j2` template with handlers. It runs on the **AWS path** (`ap-south-1`), not Multipass/MinIO (see `environment-setup.md`), and `pipeline-run2.log` shows `No changes` from Terraform and `changed=0` on all three hosts. The decision I'm most confident about is making `group_vars/kijanikiosk.yml` the only home of the SSH key path: `pipeline.sh` reads it and passes the matching `.pub` to Terraform, so the key Terraform installs and the key Ansible presents cannot drift apart (Challenge B). With more time I would replace SSH and the operator-IP allow-list with SSM Session Manager, so the pipeline works from CI runners and against private-subnet servers with no public IPs. Today that handoff is the most fragile part.
